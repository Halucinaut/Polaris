# Polaris M0 验收结论

## 状态：PASS（2026-06-05）

M0 阶段已完成。本阶段只搭建项目骨架和实验协议，不下载模型、不训练、不接入 MLX/PyTorch。

---

## 已完成内容

### 配置系统
- `polaris/config.py`：支持 base + override 递归合并，可打印完整配置或冻结到 run 目录。
- `configs/base.yaml`：定义 `project, run, model, data, training, lora, eval, logging, hardware` 顶层字段。
- `configs/qwen3_0_6b/`：SFT、DPO、GRPO 覆盖配置。
- `configs/qwen3_4b/`、`configs/qwen3_8b/`：预留配置。

### Run Registry
- `polaris/registry.py`：自动分配递增 run id（`000001_<run_name>`），创建目录结构，管理状态流转（created -> running -> completed/failed）。
- 每个 run 目录包含：`config.yaml`、`run_meta.yaml`、`metrics/`、`samples/`、`checkpoints/`、`logs/`。

### 指标与硬件日志
- `polaris/monitoring/metrics.py`：追加 JSONL 格式 train/eval 指标和 sample diff，支持安全追加不覆盖。
- `polaris/monitoring/hardware.py`：采集平台、Python 版本、内存、MLX/PyTorch/MPS 可用性；缺少依赖时返回 false/null，不报错。

### 文档模板
- `docs/templates/`：experiment_card.md、metric_report.md、sample_diff.md、failure_note.md、run_report.md。
- `scripts/generate_experiment_card.py`：根据 run_meta.yaml 和 config.yaml 生成文档骨架；默认不覆盖已有文件。

### Sanity Fake Run
- `scripts/sanity/sanity_sft.py`：写入 loss、format_adherence、answer_extraction_success。
- `scripts/sanity/sanity_dpo.py`：写入 chosen_logprob、rejected_logprob、logprob_margin、preference_accuracy、response_length_shift。
- `scripts/sanity/sanity_grpo.py`：写入 reward_mean、reward_std、kl、entropy、pass_at_1、invalid_output_rate、avg_completion_length。
- `scripts/sanity/sanity_ppo.py`：写入 rollout_count、group_size、reward_mean、policy_logprob_mean、ref_logprob_mean、kl、loss、resume_ok、checkpoint_written。
- `scripts/sanity/common.py`：统一 fake run 流水线，异常时状态置 failed 并写入 logs/error.txt。

### Makefile
- 目标：`config-check`、`create-run`、`sanity-sft`、`sanity-dpo`、`sanity-grpo`、`sanity-rl`、`sanity-all`、`list-runs`。
- `make sanity-all` 依次跑通 4 个 fake run，`make list-runs` 列出所有 run。

### README
- 包含项目定位、M0 范围、不做事项、目录说明、M0 Validation 命令。
